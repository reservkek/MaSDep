# Добро пожаловать в MaSDep!
**MaSDep (Magnetron Sputtering and Deposition)** - динамическая модель, включающая в себя расчёт скорости распыления и осаждения, характеристик осаждения, толщины и состава покрытий, получаемых методами магнетронного распыления.  

![MaSDep interface ](https://github.com/user-attachments/assets/4331eff3-095f-441e-9d4e-403caff883bd)  
  
Функционал на данный момент:  
- расчёт движения подложки в пространстве
- расчёт скорости распыления дисковых мишеней магнетронов
- расчёт скорости осаждения частиц на движущуюся подложку, в том числе с нескольких магнетронов
- расчёт энергетических характеристик осаждаемого потока
- расчёт состава мишени при осаждении с нескольких магнетронов
- расчет рассеяния осаждаемого потока на атомах рабочего газа  
  
Весь движок модели, интерфейс и интерактивное отображение объектов было реализовано с нуля при помощи библиотек OpenGL и ImGui  
На данный момент разработка заморожена
